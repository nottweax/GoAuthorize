# GoAuthorize
Сервис авторизации на голанг

auth.go - содержит функции регистрации и логина

user.go - содержит струкутру пользователя 

jwt.go - генерирует токен

main.go - открывает порт :8080 /register & /login 


использованные репозитории:

github.com/dgrijalva/jwt-go v3.2.0

github.com/gorilla/mux v1.8.1 

golang.org/x/crypto v0.37.0
